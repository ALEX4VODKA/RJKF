智慧停车收费系统（Windows x64 便携版）
========================================

一、启动
1. 完整解压 ZIP，不能只复制 exe。
2. 保留解压得到的英文文件夹名“ParkingSystem”，不要改成中文目录名。
3. 直接演示：双击“一键演示.cmd”，使用账号 test、密码 1 登录。
4. 普通使用：双击“智慧停车收费系统.exe”，首次启动按提示创建管理员账号。
5. 一键演示每次会重置独立演示库，不会覆盖普通业务数据库。

注意：ZIP 文件名、EXE 名称和界面可以是中文；只有程序所在顶层文件夹必须保留为
“ParkingSystem”。当前冻结版 QtWebEngine 在中文应用目录中可能于登录后退出。

二、数据位置
- 数据库、备份、识别抓拍和浏览器缓存都保存在程序目录下的 runtime 文件夹。
- 离线车牌识别模型也在 runtime 文件夹；请勿删除或只移动 exe。
- 迁移程序时，复制整个文件夹即可保留数据。

三、运行要求
- Windows 10/11 x64。
- 程序与车牌识别均可离线运行；无需安装 Python。
- PDF 报表使用系统中文字体，请保留 Windows 默认字体。

四、安装自检（维护人员）
在命令提示符中进入程序目录后执行：
  智慧停车收费系统.exe --verify-installation

结果写入 runtime\package-verification.json；status 为 ok 表示 3D、QtWebEngine
和离线车牌模型均已加载。

五、常见问题
- 无法保存数据：将整个程序目录放到当前用户可写的位置（如桌面或文档）。
- 3D 画面不可用：更新显卡驱动后重试；主业务仍可使用降级画面。
- 识别失败：换用更清晰、车牌更正的图片/视频，或使用人工补录。
