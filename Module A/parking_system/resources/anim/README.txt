道闸动画资源放置说明（备用方案：MP4 / 序列帧）
================================================

默认用的是**实时 3D**（three.js 渲染 resources/model/parking.glb），
本目录下的资源只在下面两种情况生效：
    · 没有 parking.glb；
    · 没装 PyQtWebEngine，或 3D 初始化失败（程序会自动降级到这一层）。

两个道闸仍然各自一套资源，文件名必须区分门位。

------------------------------------------------------------------
方案一：MP4
------------------------------------------------------------------
resources/anim/gate_in_up.mp4       入口 · 抬杆
resources/anim/gate_in_down.mp4     入口 · 落杆
resources/anim/gate_out_up.mp4      出口 · 抬杆
resources/anim/gate_out_down.mp4    出口 · 落杆

导出参数（与详细设计 2.6.4 一致）：
  分辨率  1920 × 1080
  帧率    30 fps
  时长    抬杆 1.5 ~ 2.0 s，落杆 1.5 ~ 2.0 s（48 帧 ≈ 1.6 s）
  编码    H.264（.mp4）
  首尾帧  抬杆：水平 → 抬起 85°；落杆：抬起 85° → 水平
  背景    #E8EFF7 或接近的浅灰，与界面 3D 区一致；不要留白边

------------------------------------------------------------------
可选：镜头归位（focus）片段
------------------------------------------------------------------
想让「收到信号 → 镜头飞回摄像机位 → 抬杆」这个效果，再加两段前导片：

resources/anim/gate_in_focus.mp4     入口 · 镜头归位（约 0.8 s）
resources/anim/gate_out_focus.mp4    出口 · 镜头归位（约 0.8 s）

播放顺序由程序自动串联，不需要人工切换：
    收到抬杆信号 → 播 focus → 自动接 up → 播完停在抬起帧
界面上会依次显示「镜头归位…」→「抬杆中…」→「已抬起」。

制作要点：
  1. focus 的第 1 帧是全景机位，最后一帧必须和 up 的第 1 帧机位完全一致，
     否则两段接起来会“跳”一下；
  2. 中间用 Bezier 缓动，最后 6 帧放慢，落点更稳；
  3. 只有抬杆会播 focus，落杆不再重复飞镜头。

------------------------------------------------------------------
方案二：PNG 序列
------------------------------------------------------------------
resources/anim/in/up/0001.png ... 0048.png        入口抬杆
resources/anim/in/down/0001.png ... 0048.png      入口落杆
resources/anim/out/up/0001.png ... 0048.png       出口抬杆
resources/anim/out/down/0001.png ... 0048.png     出口落杆

命名只要保证字典序等于帧序即可（0001、0002…）。
帧率由 create_animator(..., fps=30) 指定，默认 30。

------------------------------------------------------------------
都不放会怎样
------------------------------------------------------------------
3D 区显示占位画面（网格 + 道闸线稿），抬杆 / 落杆的业务信号照常发出，
状态胶囊、指标卡、在场列表都正常流转——动画没做好也不影响演示。

------------------------------------------------------------------
代码位置
------------------------------------------------------------------
界面侧：parking/ui/scene_panel.py
    ScenePanel(anim_dir, mode)
    panel.raise_gate("in" / "out")     抬杆
    panel.lower_gate("in" / "out")     落杆
    panel.lower_current()              落当前抬起的那道闸

实现侧：parking/anim/
    base.py         GateAnimator 接口（业务只依赖它）
    webgl.py        实时 3D（默认）
    video.py        MP4
    sequence.py     序列帧
    placeholder.py  占位
    __init__.py     create_animator()：3D > MP4 > 序列帧 > 占位

两个道闸共用同一个场景面板和同一台镜头，靠镜头切换区分入口 / 出口；
底层动画资源仍然是分开的（gate_in_* / gate_out_*）。
