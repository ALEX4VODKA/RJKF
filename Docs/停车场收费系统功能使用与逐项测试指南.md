# 停车场收费系统功能使用与逐项测试指南

## 1. 文档用途

本文用于指导本系统的日常使用、课程演示和逐项验收。内容覆盖：

- 一键启动与登录；
- 图片、视频和人工车牌输入；
- 车辆进场、出场、计费、缴费、授权放行及道闸动画；
- 收费标准、停车记录、统计报表与 PDF；
- FR-1～FR-8 功能测试；
- TC-01～TC-12 逐项测试；
- 自动化测试、结果记录与常见问题处理。

> 本系统为 Windows 单机演示程序。支付和道闸均为软件模拟，不连接真实支付平台、摄像头或物理道闸。

---

## 2. 测试前准备

### 2.1 推荐方式：使用压缩包

1. 将 `智慧停车收费系统_Windows_x64.zip` **完整解压**到一个普通目录。
2. 保留解压得到的英文顶层文件夹名 `ParkingSystem`，不要把程序所在文件夹改成中文。
3. 不要只把 EXE 单独拖出压缩包，程序还需要同目录下的模型、3D 场景和运行库。
4. 双击 `ParkingSystem` 目录中的 `一键演示.cmd`。
5. 等待登录窗口出现，输入：
   - 账号：`test`
   - 密码：`1`
6. 登录后会显示主界面，并自动打开“演示指引”。

便携包不需要安装 Python。首次被 Windows Defender 扫描时，启动可能比之后慢。
ZIP、EXE 和界面仍可使用中文名称；英文顶层目录是当前冻结版 QtWebEngine 的运行约束，
改成中文目录可能导致认证成功后程序在打开 3D 主界面时直接退出。

### 2.2 从 GitHub 源码运行

从 GitHub 拉取的源码还需要本机准备 Python、依赖和未纳入 Git 的识别模型。推荐使用 Python 3.12，在仓库根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "Module A\parking_system\requirements.txt"
.\.venv\Scripts\python.exe -m pip install -r "Module A\parking_system\requirements-dev.txt"
.\.venv\Scripts\python.exe "Module A\parking_system\tools\setup_recognition.py"
```

准备完成后，可选择以下方式启动：

- 一键演示：双击仓库根目录的 `一键答辩演示.cmd`；
- 普通业务库：

```powershell
.\.venv\Scripts\python.exe "Module A\parking_system\app.py"
```

普通业务库首次运行时，如果还没有账号，程序会引导创建管理员账号；一键演示模式固定使用 `test / 1`。

### 2.3 演示数据与重置规则

一键演示模式使用独立数据库，不会修改普通业务库。每次重新双击一键脚本，演示数据库都会恢复到初始状态。

初始状态包含以下预置在场车辆：

| 车牌 | 场景 | 初始预期 |
| --- | --- | --- |
| `陕A90002` | 正常收费 | 停车 3 小时 20 分，收费 11.00 元 |
| `陕A90003` | 免费停车 | 停车 10 分钟，收费 0.00 元 |
| `陕A90004` | 未缴费拦截 | 未缴费时不能放行 |
| `陕A90005` | 管理员授权 | 可填写原因并验证管理员后授权放行 |
| `陕A90009` | 跨天封顶 | 已冻结 26 小时账单，合计 60.00 元 |

为了保证测试相互独立，建议：

1. 每完成一个会使车辆离场的用例，关闭程序；
2. 再次双击一键脚本，恢复初始演示数据；
3. 道闸抬起后必须点击“车辆已通过 · 落杆”，再开始下一辆车；
4. 修改收费规则后，重新启动一键演示可恢复默认规则；
5. 不要同时启动多个演示程序实例。

## 3. 主界面功能说明

| 区域或按钮 | 用途 |
| --- | --- |
| 识别进场 | 选择真实车牌图片或视频，识别成功后登记进场 |
| 识别出场 | 选择真实车牌图片或视频，识别后查询在场记录并结算 |
| 人工进场 | 识别失败或测试时，人工输入车牌并登记进场 |
| 人工出场 | 人工输入车牌并查询账单 |
| 车辆已通过 · 落杆 | 在入口或出口抬杆后确认车辆通过，完成落杆及业务状态闭环 |
| 收费标准 | 管理员查看、新增、版本化修改或停用车型规则 |
| 停车记录 | 管理员查询在场及历史停车记录 |
| 统计报表 | 按日、周、月、季、年查询，并导出、打开或打印 PDF |
| 演示指引 | 查看演示用例、预置车牌和预期结果 |
| 中间 3D 场景 | 显示入口或出口道闸抬杆、落杆动画 |
| 右侧在场车辆 | 显示当前尚未完成离场的车辆 |

## 4. 各功能如何使用及如何测试

### 4.1 登录与权限

#### 使用方法

1. 启动程序。
2. 输入账号 `test`、密码 `1`。
3. 点击登录。
4. 登录后检查主界面右下角当前用户。

#### 测试方法

1. 输入正确账号密码，应进入主界面。
2. 退出后重新启动，输入错误密码，应提示账号或密码错误，不能进入系统。
3. 再使用正确密码登录，应能正常进入。

#### 通过标准

- 正确账号可以登录；
- 错误密码不能登录；
- 管理员可以打开收费标准、停车记录和统计报表；
- 登录失败时不泄露具体密码信息。

### 4.2 真实图片车牌识别

#### 使用方法

1. 点击“识别进场”或“识别出场”。
2. 在文件选择窗口中选择 JPG、JPEG、PNG 或 BMP 图片。
3. 等待后台识别完成。
4. 检查识别车牌、置信度和抓拍画面。
5. 如果出现多个候选，选择实际车牌；如果识别失败，按提示重试或转人工录入。

#### 测试方法

准备一张车牌完整、光照正常、文字清晰的真实车辆图片：

1. 用“识别进场”选择该图片。
2. 将界面识别结果与图片真值逐字比较。
3. 完成进场并落杆。
4. 再用同一图片执行“识别出场”。

#### 通过标准

- 界面在识别期间仍可响应；
- 成功时显示真实识别结果和置信度，不使用固定车牌冒充识别；
- 失败时有明确提示，并允许人工补录；
- 识别成功后仍经过正常进出场业务校验。

### 4.3 真实视频车牌识别

#### 使用方法

1. 点击“识别进场”或“识别出场”。
2. 选择 MP4、AVI、MOV 或 MKV 视频。
3. 程序自动抽取代表帧并识别。
4. 根据识别结果继续进场或出场流程。

#### 测试方法

准备一段不少于 10 秒、能清晰看到同一车牌的视频：

1. 选择视频并开始识别。
2. 记录识别耗时、车牌结果和置信度。
3. 将识别文本与视频中的真实车牌比较。
4. 至少使用 5 段相互独立的视频重复测试。

#### 通过标准

- 视频选择后程序不假死；
- 能从视频帧中得到车牌候选；
- 识别失败时可转人工处理；
- 每段视频的实际结果均被记录，不能只保留成功样本。

### 4.4 人工进场

#### 使用方法

1. 点击“人工进场”。
2. 输入合法车牌，例如 `陕A12345`。
3. 选择车型和牌照颜色。
4. 点击“登记并抬杆”。
5. 等待入口道闸抬起。
6. 点击“车辆已通过 · 落杆”。

#### 测试方法与通过标准

- 首次录入合法车牌：应成功保存并抬杆；
- 落杆后：右侧在场车辆应出现该车；
- 再次录入同一车牌：应提示车辆已在场，不能生成第二条未离场记录；
- 输入明显非法车牌：应提示格式错误，不能保存。

### 4.5 正常收费出场

#### 使用方法

1. 点击“人工出场”。
2. 输入 `陕A90002`。
3. 检查出场窗口中的车牌、进场时间、停车时长、图片和 11.00 元账单。
4. 点击“模拟缴费”。
5. 缴费成功后点击“抬杆放行”。
6. 返回主界面，等待出口道闸抬起。
7. 点击“车辆已通过 · 落杆”。

#### 通过标准

- 显示 3 小时 20 分左右的停车时长和 11.00 元应收金额；
- 缴费前不能正常放行；
- 缴费后可以抬杆；
- 车辆通过并落杆后才最终离场；
- 停车记录中保留账单、缴费和离场信息。

### 4.6 免费出场

#### 使用方法与测试方法

1. 重置演示数据。
2. 点击“人工出场”，输入 `陕A90003`。
3. 确认停车 10 分钟、费用 0.00 元。
4. 点击“免费放行”。
5. 点击“车辆已通过 · 落杆”。

#### 通过标准

- 费用为 0.00 元；
- 按钮显示“无需缴费”或“免费放行”；
- 无需模拟缴费即可放行；
- 离场记录状态正确，不被记为未缴费逃费。

### 4.7 未缴费拦截

#### 使用方法与测试方法

1. 重置演示数据。
2. 人工出场输入 `陕A90004`。
3. 不点击“模拟缴费”，直接点击“抬杆放行”。

#### 通过标准

- 系统提示需要先缴费；
- 出口道闸不抬起；
- 车辆仍保留在在场列表；
- 数据库中不能被提前标记为已离场。

### 4.8 管理员授权放行

#### 使用方法

1. 重置演示数据。
2. 人工出场输入 `陕A90005`。
3. 点击“授权放行”。
4. 填写明确原因，例如“现场设备故障，管理员授权”。
5. 按提示输入管理员账号 `test` 和密码 `1`。
6. 验证成功后抬杆，最后点击“车辆已通过 · 落杆”。

#### 通过标准

- 原因不能为空；
- 错误管理员密码不能授权；
- 正确验证后允许放行；
- 停车记录和统计报表能区分正常实收与授权放行；
- 授权原因和操作人被写入审计记录。

### 4.9 跨天计费与日封顶

#### 使用方法与测试方法

1. 重置演示数据。
2. 人工出场输入 `陕A90009`。
3. 查看已冻结账单及逐日明细。

#### 通过标准

- 停车时长为 26 小时；
- 总费用为 60.00 元；
- 明细分为两个自然日，每日最多 30.00 元；
- 多次打开账单，金额不随当前时间继续增长。

### 4.10 收费标准管理

默认小型车规则为：免费 15 分钟；免费期后首 2 小时 5.00 元；超出后每小时 3.00 元，不足 1 小时按 1 小时计；每日封顶 30.00 元。

#### 使用方法

1. 点击顶部“收费标准”。
2. 选择现有车型规则。
3. 使用“新增车型规则”“版本化修改”或“停用车型规则”。
4. 保存后关闭窗口。

#### 测试方法

1. 先查询预置车辆 `陕A90002`，记录其冻结账单 11.00 元。
2. 打开“收费标准”，对小型车执行“版本化修改”，例如将超时价改为 4.00 元。
3. 人工录入一辆新的测试车完成进场、出场和计费。
4. 再查看 `陕A90002` 的既有账单。
5. 测试完毕后重启一键演示恢复默认规则。

#### 通过标准

- 新规则保存后立即用于新进场记录；
- 已存在记录保留进场时规则快照；
- 已冻结账单仍为 11.00 元，不被新规则追溯修改；
- 非法参数，如负金额或日封顶低于首时段价格，不能保存。

### 4.11 停车记录查询

#### 使用方法

1. 点击“停车记录”。
2. 按车牌、状态或时间条件查询。
3. 查看进场时间、出场时间、费用、缴费状态和放行方式。

#### 测试方法与通过标准

- 查询预置在场车牌，应显示尚未离场；
- 完成一辆车的出场闭环后再次查询，应显示完整历史；
- 授权放行记录应与正常缴费记录区分；
- 关闭并重启普通业务模式后，历史记录仍存在；
- 一键演示重启会故意重置演示库，这不属于数据丢失。

### 4.12 统计报表

#### 使用方法

1. 点击“统计报表”。
2. 选择开始日期、结束日期及日、周、月、季或年维度。
3. 点击“查询”。
4. 查看车次、应收、实收、授权放行车次和授权金额。

> 查询时间区间采用“包含开始时间、不包含结束时间”的口径。例如查询 11 月 1 日全天，结束时间应选 11 月 2 日 00:00。

#### 测试方法

1. 使用一键演示预置的最近 30 天数据。
2. 依次选择日、周、月、季、年并点击“查询”。
3. 记录各维度合计。
4. 缩小日期范围，确认结果随范围变化。
5. 完成一笔正常缴费或授权放行后再次查询，检查相关指标变化。

#### 通过标准

- 五种维度均能返回结果；
- 同一时间范围的汇总总车次和总金额口径一致；
- 应收、实收与授权未收分开显示；
- 空时间范围显示空结果，不崩溃、不伪造数据。

### 4.13 PDF 报表

#### 使用方法

1. 先在“统计报表”中执行查询。
2. 点击“导出 PDF”，选择保存位置。
3. 导出后点击“打开 PDF”。
4. 需要打印时点击“打印 PDF”。

#### 测试方法与通过标准

- PDF 文件成功生成且大小不为 0；
- 文件能被系统 PDF 阅读器打开；
- 中文标题、时间范围、统计表格和金额显示完整；
- 多页报表无文字截断或乱码；
- “打印 PDF”能调用系统打印流程；没有打印机时，至少应出现系统打印界面或明确错误提示。

### 4.14 3D 道闸与业务状态

#### 使用方法与测试方法

1. 完成一次进场登记，观察入口抬杆。
2. 点击“车辆已通过 · 落杆”，观察入口落杆。
3. 完成一次缴费出场，观察出口抬杆。
4. 点击“车辆已通过 · 落杆”，观察出口落杆。

#### 通过标准

- 业务登记成功后才抬杆；
- 未缴费时出口不能抬杆；
- 抬杆完成不等于车辆已经离场；
- 只有确认车辆通过并落杆后，离场状态才最终完成；
- 动画失败时应明确提示，不得静默把车辆标记为已通过。

## 6. TC-01～TC-12 逐项测试步骤

除特别说明外，每个用例开始前都建议重启一键演示，使用 `test / 1` 登录。

### TC-01：正常识别进场

**前置条件：** 准备一张未在场车辆的清晰真实车牌图片。

**步骤：**

1. 点击“识别进场”；
2. 选择真实图片；
3. 核对识别车牌和置信度；
4. 确认登记；
5. 观察入口抬杆；
6. 点击“车辆已通过 · 落杆”；
7. 在右侧在场车辆或“停车记录”中查询。

**预期：** 识别结果正确，进场记录持久保存，入口抬杆后能正常落杆，车辆出现在在场列表。

### TC-02：正常收费出场

**测试数据：** `陕A90002`。

**步骤：** 人工出场查询 → 核对 11.00 元 → 模拟缴费 → 抬杆放行 → 车辆已通过并落杆 → 查询停车记录。

**预期：** 3 小时 20 分收费 11.00 元；缴费前不能正常放行；缴费、放行、离场状态和历史记录完整。

### TC-03：免费时段出场

**测试数据：** `陕A90003`。

**步骤：** 人工出场查询 → 核对 0.00 元 → 免费放行 → 车辆通过并落杆。

**预期：** 10 分钟在免费时长内，费用 0.00 元，无需模拟缴费即可放行。

### TC-04：未缴费禁止放行

**测试数据：** `陕A90004`。

**步骤：** 人工出场查询 → 不缴费直接点击“抬杆放行”。

**预期：** 提示先缴费，出口不抬杆，车辆仍在场，不能生成已离场记录。

### TC-05：管理员授权放行

**测试数据：** `陕A90005`。

**预期：** 验证成功后允许放行；记录包含操作人和原因；报表单独统计授权车次及授权金额。

**预期：** 识别过程不使程序崩溃；失败原因明确；最多 3 次尝试后可转人工录入；人工录入仍经过正常业务校验。

## 10. 常见问题

### 10.1 双击后没有启动

- 确认已经完整解压 ZIP；
- 不要从压缩软件预览窗口直接运行；
- 检查杀毒软件是否正在扫描或隔离文件；
- 查看程序目录下 `runtime` 中的启动错误日志；
- 尝试在 PowerShell 中执行安装自检命令。

### 10.2 图片或视频始终识别失败

- 确认文件格式受支持；
- 优先使用车牌完整、光照正常、分辨率足够的素材；
- 源码模式先运行 `tools\setup_recognition.py`；
- 便携包确认离线模型目录未被删除；
- 失败时使用系统提供的人工录入，不要把人工结果当成自动识别成功。

### 10.3 车辆无法开始下一步

- 检查当前道闸是否仍处于抬起状态；
- 点击“车辆已通过 · 落杆”完成上一辆车；
- 确认没有未关闭的出场结算窗口；
- 必要时关闭程序并重新运行一键演示恢复状态。

### 10.4 报表没有数据

- 检查查询日期是否覆盖演示数据；
- 注意结束时间不包含在查询范围内；
- 先使用最近 30 天范围测试；
- 确认当前登录用户是管理员。

### 10.5 为什么一键演示重启后刚才的数据没有了

这是设计行为。一键演示每次都从模板重建独立演示库，以保证所有预置用例可以重复执行。需要长期保存业务数据时，应使用普通启动方式，而不是一键演示脚本。
